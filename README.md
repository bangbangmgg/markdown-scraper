# Fast CLI Web-to-Text Scraper for LLMs & RAG

A lightning-fast, dependency-free Python CLI tool designed for developers, researchers, and AI engineers to extract clean text from any webpage instantly for RAG pipelines and LLM context.

## Features
- **Zero Heavy Dependencies**: Uses standard Python libraries (`urllib`, `html.parser`).
- **Fast & Lightweight**: Instant execution, perfect for CLI automation and cron jobs.
- **File Export**: Save directly to `.txt` or `.md` for ingestion into vector databases.

## Installation & Usage

1. Clone or download the script:
   ```bash
   git clone https://github.com/yourusername/markdown-scraper.git
   cd markdown-scraper
   ```

2. Run the scraper:
   ```bash
   python scraper.py https://example.com -o output.txt
   ```
